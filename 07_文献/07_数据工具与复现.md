## 2. V1-A 用什么

V1-A 的模型层就是 V0 的 RWR + 校正 + 模块：

| 组件 | 路径 | 说明 |
|---|---|---|
| 5 折划分 | `data/folds/fold_0..4/` | 冻结，不改 |
| 候选基因 | `data/folds/candidate_gene_universe.parquet` | 16,992 个（2026-09 数据） |
| 异质图 | `data/graphs/fold_*/A_*.npz`、`transition_matrix.npz` | 行随机，CPU |
| RWR | `src/phenotype_network_v0/models/rwr.py` | 主模型 |

| 模块 | `src/phenotype_network_v0/models/modules.py`、`scripts/11_detect_modules.py` | Leiden + 100 次扰动 |
| 路径 | `src/phenotype_network_v0/models/explanations.py` | ≤4 跳 |
| 评价 | `src/phenotype_network_v0/evaluation/*` | 指标、bootstrap、消融 |

V1 新增的可复用部分：

| 组件 | 路径 | 用途 |

## 5. 科学结果

V1-A 的主分数是 raw RWR：

| 模型 | Recall@10 | MRR |
|---|---|---|
| raw RWR | 0.0896 | 0.0618 |
| calibrated | 0.0221 | 0.0144 |
| semantic_max | 0.0835 | 0.0608 |
| gene_degree | 0.0066 | 0.0056 |
| random | 0.0007 | 0.0007 |

GNN 分支的 5 折结果只作负结果记录：

| Fold | GNN MRR | GNN R@10 | RWR MRR | RWR R@10 |
|---|---|---|---|---|
| 0 | 0.0196 | 0.0337 | 0.0400 | 0.0787 |
| 1 | 0.0096 | 0.0133 | 0.0332 | 0.0244 |
| 2 | 0.0318 | 0.0696 | 0.0905 | 0.1253 |
| 3 | 0.0296 | 0.0455 | 0.0522 | 0.0795 |

结论：GNN 分支低于 RWR，不进入 V1-A；V1-A 的校准也偏保守，raw 是主分数。

## 6. 命令

```bash

python scripts/08_run_rwr.py --config configs/real.yaml
python scripts/09_calibrate_scores.py --config configs/real.yaml
```

```bash
python scripts/v1/01_build_learning_data.py --fold all
```

```bash
python scripts/v1/03_train_conditioned_model.py --fold 0 --device cuda
python scripts/v1/08_evaluate_v1.py --config configs/v1/default.yaml
python scripts/v1/verify_v1.py --config configs/v1/default.yaml
```

## 7. 环境

- V1-A：Python 3.11+，numpy/pandas/scipy/pyarrow/PyYAML/igraph/leidenalg/statsmodels；CPU 即可，不需要 torch。
- GNN 分支：PyTorch + PyTorch Geometric + CUDA；见 `requirements-v1-lock-linux.txt`。
- 数据约 2 GB，V1-A 输出约 600 MB；GNN checkpoint 每折约 93 MB。
- 迁移时只拷 `data/`、`outputs/`、`src/`、`scripts/`、`configs/`，不拷 `.venv`、`__pycache__`。
