# 论文方案：以方向二为中心，V1 为导向

> 2026-10-28 口径修订：关联数改用唯一 (disease, gene) 对 **568**（原始记录 688 行）；分层 T1=9、T2=17、T3=426、T4=18。复算见交接包根目录的 `CORRECTIONS.md`。

## 1. 一句话

论文研究「表型驱动网络上的可靠机制模块发现与评价」，用 V1-A 的心血管数据、RWR 分数、Leiden 模块和评价脚手架作为导向案例；V1 的 GNN 分支负结果只作动机和边界，不作为论文模型。

## 2. 题目候选

中文：表型约束下稳健疾病机制模块的发现与可靠性评价

英文：Reliable phenotype-constrained disease module discovery: a robustness and bias-aware evaluation framework

不要写成「HGCN 做疾病模块」或「V1 优于 RWR」。V1 是案例，方向二是主体。

## 3. 研究问题

- RQ1：现有「传播 + Leiden」模块里，有多少是疾病特异的，多少是度数/通用模块？
- RQ2：表型特异性、结构紧密性、扰动一致性三个约束，能否提升模块可靠性？
- RQ3：在随机表型、度数匹配、同度数随机网络下，可靠性评价是否校准？
- RQ4：共享/特异模块与心血管外部证据（血管 PPI、CAD 基因集、STARNET GRN）是否一致？
- RQ5：以 V1 为导向案例，排序器从 RWR 到未来 HGCN 时，模块结论如何变化？

## 4. 贡献

C1 可靠性评价框架：R1 疾病特异性、R2 结构稳健性、R3 结构偏差、R4 功能一致性、R5 可重复性、R6 实用性；每项配零模型和接受阈值。

C2 三约束模块发现与稳定核心：表型特异性 + 结构紧密性 + 扰动一致性，共识聚类 + 核心/外围 + 局部精修。

C3 基准与边界：V1 GNN 分支五折低于 RWR、数据审计（568 个唯一关联对、原始 688 行、94.2% 疾病只有 1–2 个正样本）作为「数据天花板」证据，说明为什么主指标不能只靠基因恢复。

C4 心血管应用：452 个疾病、2,839 个 V0 模块、CVD 外部证据；共享/特异模块和关键连接。

一句话：V1 是「导向案例 + 数据/评价基础设施」，不是论文的算法贡献。

## 6. 论文结构

1. Introduction：模块发现的可靠性缺口；现有方法多为单一划分、缺零模型；V1 案例。
2. Related work：模块方法（DIAMOnD、Leiden、ROBUST、DOMINO）、评价与偏差（DREAM、CoLiPE、Lazareva）、表型传播（RWR、Phenolyzer）。
3. Data：V0/V1-A 数据、折划分、候选集、数据分层（T1–T4）。
4. Methods：传播与校准、模块发现、三约束、可靠性框架。
5. Experiments：数据、基线、指标、零模型、消融、实现细节。
6. Results：主结果、偏差、稳健性、外部证据、共享/特异。
7. Discussion：数据天花板、V1 负结果、GNN 作为未来工作。
8. Limitations：标签稀疏、Reactome 循环、外部证据覆盖、无因果。

## 8. 写作顺序

1. 先写 Methods 的可靠性框架（不依赖结果）。
2. 再写 Data 与数据审计（已有事实）。
3. 跑 E1–E4，写 Results 的模块质量与偏差。
4. 跑 E5–E7，写稳健性与外部证据。
5. 最后写 Intro/Discussion，把 V1 负结果放进边界，不放进主贡献。

## 9. 口径

- 论文中心是「可靠模块的发现与评价」，V1 是导向案例。
- 不写「HGCN 提升了模块」；GNN 分支是负结果，只作未来工作。
- 基因恢复指标只在 T1/T2 报告；T3 只报不依赖正样本的 z_spec、稳定性、GO。
- Reactome 只作图内证据；GO/GWAS/Zhu/Hecker/Koplev 作外部证据。
- 不写因果。
