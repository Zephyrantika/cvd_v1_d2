## 结论摘要

基线（RWR + Leiden）在五折 2,839 个模块上给出可复现的可靠性分级：A 级 45.3%，q≤0.05 占 87.0%，z_spec 中位 1.41。

方法对照九种（fold 0，同大小 25 基因）：Leiden 基线 2.19，ROBUST 精确 PCST 2.13（48/91，p=0.60，打平），最大连通分量 1.88，DOMINO 式 1.79，Heinz 1.76，MWCS 精确 1.66，DIAMOnD 1.65（70/90 输，p=1.7e-9）。差异来自评测与构建同源：z_spec 使用 RWR 分位，而 Leiden 模块就是从同一分位的前 200 个基因中切出的密集簇。

换一条与分数无关的轴（独立扰动复现率）：三约束共识 0.853 对基线 0.730，五折全胜（0.894/0.788/0.884/0.809/0.889 对 0.824/0.617/0.775/0.663/0.772），87 个疾病中 80 个更好；代价是 z_spec 低 11%，A 级持平（55.5% 对 55.1%）。

两条负结果：关键连接（删模块内边介数前十的边，分数变化 1e-9 量级，五折一致）与共享/特异（4,024/4,095 个疾病对模块相似度超阈值，只切出两个社区）。
