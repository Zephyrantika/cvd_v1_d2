# 方向二总描述

表型约束下的稳健机制模块发现与可靠性评价

## 一、这个方向要解决什么

心血管疾病在蛋白互作网络上的模块，多数是高分基因聚出来的通用团块：它们看起来紧密，但换个疾病也成立。方向二要回答的是，一个模块到底是疾病特异的，还是高度数基因凑出来的；它在表型缺失和网络扰动下稳不稳；它和独立的心血管证据是否一致。

方向二不训练排序器。它固定使用上游给的传播分数，只在模块层做发现与评价。这一条既是分工，也是边界：排序层的上限（下详）不由本方向负责。

## 二、数据

452 个心血管疾病，16,992 个候选基因，5 折疾病家族互斥划分，异质图（表型、基因、PPI、Reactome 通路）。

疾病—基因标签从 568 对扩到 1,761 对，来源包括原始标签、ClinVar、ClinGen、DisGeNET、Open Targets，其中 curated 口径下有 127 个疾病达到 5 个以上已知基因。标签只用于评价与分层，不进图、不参与阈值选择。

数据链整合为 10 张表（病、基因、表型、通路及四张事实表），另有 16 个外部来源单独解析，地址与体量见 `DATA_SOURCES.md`。

## 三、方法

### 3.1 基线

每个疾病取传播分位前 200 的基因，在 STRING 700 诱导子图上跑 Leiden，取最大模块。这是整个项目原有的做法，也是全部对照的基准。

### 3.2 三约束模块发现

第一步，共识。对每个疾病做 100 次表型扰动（删除部分术语），每次重跑传播与 Leiden，得到共现矩阵；按 0.8 与 0.6 两个阈值把成员分为核心与外围。这一步解决“单次划分不稳定”。

第二步，精修。在候选集内做成员替换，目标函数为

f = z_spec + λ · 平均共识频率 − μ · hub

λ 与 μ 取 1 时两项尺度对齐。替换只在模块邻居内进行，保证结构不被破坏。

第三步，选点。对每个疾病生成 λ × μ × 规模共 26 个候选模块，计算各自的 z、复现率、hub、密度，取非支配集；在“复现率 ≥ 0.7 且 hub ≤ 0.5”的候选里选 z 最大的一个。规则在看结果之前固定，对全部疾病一致。

### 3.3 评价指标

传播分位 r_d 与模块均值 S(M,d)；疾病特异性 z_spec，背景是与本病表型最相似但不同家族的 20 个疾病；密度、conductance、hub 三个结构量；扰动一致性两个口径，一是核心成员的 Jaccard（τ=0.8，两半扰动互比），二是复现率（独立扰动中是否存在覆盖 60% 成员的模块）。

零模型四个：随机表型、度数保持、随机网络、同大小同度数随机模块。分级为 A/B/C，A 级要求 p_spec ≤ 0.01、复现率 ≥ 0.7、hub ≤ 0.5、GO FDR ≤ 0.05。

## 四、结果

### 4.1 主结果（五折 452 疾病）

| 指标 | 基线 | 本方法 | 检验 |
|---|---|---|---|
| A 级比例 | 22.6% | 50.9% | McNemar p=2.3×10⁻²⁹ |
| 仅 p_spec ≤0.01 | 31.6% | 56.0% | p=2.6×10⁻²⁰ |
| 样本外 z（交叉拟合） | 0.722 | 0.858 | 304/434，p=1.1×10⁻¹⁸ |
| core Jaccard | 0.8466 | 0.9125 | 303/452，p=3.6×10⁻²² |
| 复现率（共识口径） | 0.730 | 0.853 | 五折全胜 |
| 模块密度 | 0.253 | 0.360 | p=4.4×10⁻²⁹ |
| hub 集中度 | 0.182 | 0.156 | p=2.4×10⁻²⁷ |
| 攻击容忍度 | 0.841 | 0.892 | p=5.2×10⁻⁶ |

分折 A 级：46.2→73.6、18.7→42.9、18.9→48.9、13.3→48.9、15.6→40.0。基线波动大，本方法的下限明显更高。

### 4.2 六个对照

公平基线（基线也可在五个规模里选）26.8%，不截断基线 48.4%，换扰动种子口径 21.0%→48.4%（p=1.7×10⁻²¹），ClinGen 高置信子集 34.5%→70.9%（增 20 减 0），九种阈值组合下均高出 19–28 个百分点，hub 阈值取 0.3 或 0.7 结论不变。

### 4.3 外部效度

GO 富集更好；表型一致性四折更好、三折显著；表达一致性三折略好；GWAS 在度数匹配零模型下五折无显著差异；跨网络改社区富集检验后无差异。没有一项显著更差。

### 4.4 验收门

G0 数据规模、G0b 扩增后 T1≥30、G2 逐位复现、G3 空模块 KS 检验（假阳性 1.0%/5.0%）、G4 两个独立外部来源均通过；G5 部分通过，去掉稳定性约束后主指标只降 0.01，说明目标函数里那一项冗余。

## 五、边界与未解决

候选集可达性是硬上限。已知基因的传播分位中位为 0.94，即排在前 6%，而模块只取前 1.2%，所以只有三成能进候选。模块层几乎没有损失（全部模块的并集召回与候选集上限几乎相等），瓶颈在排序层。

方法新颖度有限。共识、约束精修、Pareto 选点在文献里都有，本方向的贡献是把它们组合成一套可复现的可靠性评价并给出同口径对照。

三项扩展试过且无效：加入表型一致性的三目标选点使 A 级从 73.6% 降到 64.8%；候选集放宽到 500 使 A 级从 46.2% 降到 12.1%；并集网络对召回无影响。这三条说明 A 级的优势本质是用更特异的成员换来的，任何以特异性为代价的扩展都会净亏。

## 七、与主项目的接口

模块表每行一个疾病—模块，字段包括 module_id、疾病、基因列表、大小、z_spec、p_spec、q_spec、core Jaccard、复现率、密度、hub、GO FDR、tier、A/B/C 等级。

三个接口：给定疾病与基因集算可靠性指标；给定模块集批量分级；给定新分数矩阵重跑整套流程。

需要主项目知道的三件事：可靠性分数只对“已经进入候选集的基因”有意义；GWAS 类证据要在度数匹配口径下解释；跨网络比较只能做社区富集，不能做成员重合。
