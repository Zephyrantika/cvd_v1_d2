# 五折总结（截至 2026-11-19）

数据：452 个疾病、5 折（每折 78–91 个测试疾病）、16,992 个候选基因、STRING 700 网络。
所有对比均在折内完成，未做跨折调参；A/B/C 相关的 p 值统一由 100 次随机表型零模型计算。

拆开看两个判据：仅 p_spec≤0.01，基线 31.6% 对 R1 56.0%（p=2.6×10⁻²⁰，选点未用 p，完全独立）；仅复现率≥0.7，72.6% 对 88.5%（选点用了复现率，有选择效应）。

## 六、外部验证（不利或不可迁移）

## 八、结论与限制

结论：在表型驱动的模块发现中，用"共识核心 + 稳定性约束精修 + Pareto 选点"可以得到比基线更可靠、更稳定、更抗打击的模块，代价是常见变异（GWAS）支持下降。

限制：
1. z_spec 与模块构建同源，交叉拟合缓解但未消除。
2. A 级的稳定性一半受选点影响（选点用复现率），尽管换种子验证后仍成立。
3. GWAS 支持下降，机制是去中心化换掉了枢纽上的多效性信号。
4. 跨网络不可迁移（STRING 与心脏网络之间）。
5. 已知基因召回仍不足 10%，瓶颈在排序与标签密度，不在模块方法。
6. 标签 1,761 对，其中 curated 来源为主，Open Targets 低分关联只作先验。
